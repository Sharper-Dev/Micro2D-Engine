# Micro2D-Engine

A lightweight 2D micro-engine written in Lua, designed for the Nintendo 3DS and originally created for [Tile Puzzle Ultimate](https://github.com/Sharper-Dev/Tile-Puzzle-Ultimate-For-3DS). It was built on top of [Lua Player Plus (LPP)](https://github.com/Rinnegatamante/lpp-3ds) by Rinnegatamante.

## Links

- **[Documentation](https://sharper.dev.br/Micro2D-Engine/)**: Explore the complete API reference, module guides, and generated documentation for the engine.
- **[Tile Puzzle Ultimate](https://github.com/Sharper-Dev/Tile-Puzzle-Ultimate-For-3DS)**: Check out the official repository of the game that inspired and uses this engine.
- **[Lua Player Plus (LPP-3DS)](https://github.com/Rinnegatamante/lpp-3ds)**: The homebrew interpreter and library used as the base for running Lua on the 3DS.
