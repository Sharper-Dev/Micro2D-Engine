Module systems_input_settings

Configures input dead zones and motion-control state.

Info:

  • Author: Sharper Dev

InputSettings.setCirclePadDeadZone (value) Sets the per-axis dead-zone threshold for the Circle Pad.
InputSettings.getCirclePadDeadZone () Returns the configured Circle Pad dead-zone threshold.

Circle Pad

InputSettings.setCirclePadDeadZone (value)
Sets the per-axis dead-zone threshold for the Circle Pad.

The default value is 20.

Parameters:

  • value integer The dead zone value.

Usage:

    InputSettings.setCirclePadDeadZone(10)
InputSettings.getCirclePadDeadZone ()
Returns the configured Circle Pad dead-zone threshold.

The default value is 20.

Returns:

    integer The dead zone value.

Usage:

    local deadZone = InputSettings.getCirclePadDeadZone()

C-Stick

InputSettings.setCStickDeadZone (value)
Sets the per-axis dead-zone threshold for the C-Stick.

Parameters:

Usage:

    InputSettings.setCStickDeadZone(10)
InputSettings.getCStickDeadZone ()

Returns:

    integer The dead zone value.

Usage:

Tilting

InputSettings.setTiltingState (state)
Enables or disables both the gyroscope and accelerometer.

Parameters:

  • state boolean Whether to enable or disable the controls.

Usage:

    InputSettings.setTiltingState(true)
