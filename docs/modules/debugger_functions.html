Module debugger_functions

Debugger module containing functions for the Micro2D debugger.

Info:

  • Author: Sharper Dev

Functions

Functions.detectMove () Moves the selected debug object in response to directional input.
Functions.detectFunction () Handles debugger shortcuts while the function key is held.

Fields

functionKey The key used to trigger debugger functions.
quickStepKey The key used to quickly step the debug object movement.
disableKey The key used to disable the debugger.
switchToTopKey The key used to switch to the top debug screen.
switchToBottomKey The key used to switch to the bottom debug screen.
switchObjectToNextKey The key used to switch to the next debug object.
switchObjectToPrevKey The key used to switch to the previous debug object.

Local Functions

switchObject (isForward) Internal function that switches to the next or previous debug object.


Functions

Functions.detectMove ()
Moves the selected debug object in response to directional input. Holding the quick-step key increases each movement from 1 to 10 units.

Usage:

    Functions.detectMove()
Functions.detectFunction ()
Handles debugger shortcuts while the function key is held.

Usage:

    Functions.detectFunction()

Fields

functionKey
The key used to trigger debugger functions. | Default: KEY_L
quickStepKey
The key used to quickly step the debug object movement. | Default: KEY_R
disableKey
The key used to disable the debugger. | Default: KEY_B
switchToTopKey
The key used to switch to the top debug screen. | Default: KEY_DUP
switchToBottomKey
The key used to switch to the bottom debug screen. | Default: KEY_DDOWN
switchObjectToNextKey
The key used to switch to the next debug object. | Default: KEY_DRIGHT
switchObjectToPrevKey
The key used to switch to the previous debug object. | Default: KEY_DLEFT

Local Functions

switchObject (isForward)
Internal function that switches to the next or previous debug object.

Parameters:

  • isForward boolean Whether to switch to the next or previous object.
