Module components_boxcollider

Axis-aligned box collider attached to a game object.

Info:

  • Author: Sharper Dev

Functions

BoxCollider:new (gameObject) Creates a collider with a default size of 10×10 and registers it with the collision system.
BoxCollider:setLayer (layer) Moves this collider to a collision-system layer.
